
# Weather Forecast App

A simple web app to get current weather and short forecast for any city, using the OpenWeatherMap API.

## Setup

1. **Get an OpenWeatherMap API Key**  
   Sign up for free at [openweathermap.org/api](https://openweathermap.org/api)

2. **Add your API Key**  
   In `app.js`, replace:  
   ```js
   const API_KEY = "YOUR_OPENWEATHERMAP_API_KEY";
   ```
   with your key.

3. **Run/App usage**  
   Open `index.html` directly in your browser.  
   Or deploy using GitHub Pages!

## Deployment

1. Go to your **repo Settings > Pages**  
2. Set source to `main` branch `/ (root)`  
3. Save and wait for your published site  
   - The default link will be:  
     `https://sharmfans.github.io/Weather-forecast-App/`
4. Share and use your live weather app!
